
# VivaASuaMente 🧠

VivaASuaMente é um jogo indie 2D de plataforma e exploração, desenvolvido em pixel art. O projeto combina aventura, missões, exploração de cenários e confrontos contra chefes que representam conflitos emocionais.

O protagonista, Wander, enxerga o mundo em tons de cinza. Ao explorar lugares, conhecer pessoas e realizar pequenas ações, o mundo começa gradualmente a recuperar suas cores.

## 🌌 Sobre o jogo

O projeto busca transformar emoções e experiências humanas em elementos da jogabilidade, contando uma história sobre dificuldades, descobertas, conexões humanas e esperança.

## ✨ Características

- Exploração de cenários 2D.
- Arte em pixel art.
- Missões e interações com personagens.
- Chefes inspirados em conflitos emocionais.
- Mundo que recupera suas cores ao longo da jornada.
- Atmosfera que alterna entre momentos melancólicos e acolhedores.

As funcionalidades estão em desenvolvimento e podem mudar conforme a evolução do projeto.

## 👹 Chefes planejados

## 🛠️ Tecnologias

- Godot Engine 4.x
- GDScript
- Pixel art

A versão exata da Godot deve ser conferida no arquivo `project.godot`.

## 🚀 Como executar

### 1. Instale a Godot

Baixe a Godot Engine pelo site oficial:

https://godotengine.org/download/

Utilize uma versão compatível com o projeto.

### 2. Baixe o projeto

Clone o repositório:

```bash
git clone 
```

Entre na pasta:

```bash
cd VivaASuaMente

### 3. Importe o projeto

1. Abra a Godot Engine.
2. Clique em Importar.
3. Selecione o arquivo `project.godot` na pasta do projeto.
4. Aguarde a importação dos recursos.
5. Abra o projeto.

### 4. Execute o jogo

- Pressione **F5** para executar a cena principal.
- Pressione **F6** para executar a cena atual.

## 🧪 Como testar

Após abrir o projeto na Godot:

1. Execute o jogo com F5.
2. Verifique se a cena inicial carrega corretamente.
3. Teste a movimentação para os dois lados.
4. Teste os saltos e confira se o personagem aterrissa corretamente.
5. Aproxime-se dos objetos interativos e pressione E.
6. Verifique se a missão inicial pode ser realizada.
7. Explore os cenários e teste as interações com os personagens.
8. Se os chefes estiverem acessíveis, teste seus movimentos e padrões de ataque.
9. Observe se as transições entre cenas funcionam.
10. Confira os painéis de saída e depuração da Godot para identificar erros.

### Verificação de erros

Execute o projeto pela Godot e confira os erros apresentados no editor e durante a execução. Corrija os problemas encontrados e teste novamente.
